# Project rules

- Stack: Vite, React, TypeScript, Tailwind, motion. No new dependencies.
- Edit only the files named in the prompt. Do not re-read the whole repo.
- Use tokens from `src/styles/tokens.css`. No hardcoded colors or fonts.
- Use existing files in `assets/`. Never invent images, logos, or copy.
- Project and client data lives in `src/data/`. Components only map over it.
- All animation uses motion and honors `prefers-reduced-motion`.
- After each task: run `npm run build`, fix errors, stop. Reply in 5 lines max.
